# Nat Studio portfolio

React single-page app powered by Vite, Tailwind CSS, and the React Compiler.

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build locally
- `npm run lint` — run Oxlint

## Setup

The React Compiler is enabled through Vite's Babel preset. Tailwind CSS is enabled through the official Vite plugin and imported from `src/index.css`.

See the [React Compiler documentation](https://react.dev/learn/react-compiler) and [Tailwind CSS Vite guide](https://tailwindcss.com/docs/installation/using-vite) for more information.
